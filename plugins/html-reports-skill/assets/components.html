14Hand-drawn inline SVG

For pictures that are not nodes and edges — a floor plan, a layout sketch. Anything with boxes and arrows in it is a graph diagram, which derives its own geometry. Hand-drawn SVG is the one thing here that nothing validates: the build cannot see a reversed edge or a stranded arrowhead. Rasterize the report and look at it.

Arrowheads are markers, never a second path

.s-edge is fill: none, so a head drawn as its own closed path has three coordinates that must be kept in sync with an endpoint in a different string. They drift. Define one <marker> holding a .s-arrow path and point every edge at it with marker-end; the head then lands on the line wherever the line ends. build_report.py rejects a closed .s-edge path and a marker-end naming a marker nobody defined.

        <marker id="cmp-arw" viewBox="0 0 10 10" refX="9" refY="5" markerWidth="7" markerHeight="7" orient="auto-start-reverse">
          <path class="s-arrow" d="M0,0 L10,5 L0,10 Z"/>
        </marker>

15Graph diagram

Schemas, pipelines, service maps, state machines. Declare nodes and edges; every coordinate, arrowhead and self-loop is derived, so nothing has to be kept in sync by hand.

Markup 
<div class="svgbox"><div id="gph-demo"></div></div>

Report.graph("#gph-demo", [
  { id: "org",   label: "Organisation", sub: "tenant root", cat: 0 },
  { id: "site",  label: "Site",         sub: "1 per address", cat: 1 },
  { id: "asset", label: "Asset",        sub: "serialised", cat: 2 },
  { id: "read",  label: "Reading",      sub: "append only", cat: 3 },
  { id: "user",  label: "User", cat: 4, col: 1, row: 1 }   // pinned; the rest lay themselves out
], [
  { from: "org",   to: "site",  label: "1 : n" },
  { from: "site",  to: "asset", label: "1 : n" },
  { from: "asset", to: "read",  label: "1 : n" },
  { from: "asset", to: "asset", label: "parent asset" },    // self-loop, drawn for you
  { from: "org",   to: "user",  label: "1 : n" },
  { from: "user",  to: "read",  label: "recorded by", kind: "alt" }
], {
  label: "Data model",
  groups: [{ label: "Tenanted", nodes: ["org", "site", "user"] }]
