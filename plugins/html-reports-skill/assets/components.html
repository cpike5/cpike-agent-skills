Report components

Every component in the base template, rendered, with the markup that produces it. Copy from here; do not invent new classes.

How to use this file

Start from assets/body.html. When you need a component, open the Markup disclosure below it here and copy the block. Toggle the theme with the button in the corner to check both schemes before delivering.

01Masthead

Every report. Identity, date, authority, and what the document is not.

Draft — not for circulation

Programme · document type

One or two sentences on what this answers and for whom.

Prepared by: Name Date: 1 January 2026 Status: Pre-quote review — not a quotation

  <div class="banner">Draft — not for circulation</div>

06Notes and callouts

A point that must not be skimmed past. The label names the kind of point it is.

Decision needed

Default treatment — attention, open question, pending answer.

Risk

Something that costs money or time if ignored.

Confirmed

Something that landed, or came in cheaper than assumed.

Context

Background the reader needs but did not ask for.

Aside

Neutral, low-emphasis.

Markup 
<div class="note">
  <span class="lbl">Decision needed</span>
  <p>Default treatment — attention, open question, pending answer.</p>
</div>
<div class="note risk"><span class="lbl">Risk</span><p>Something that costs money or time if ignored.</p></div>
<div class="note good"><span class="lbl">Confirmed</span><p>Something that landed, or came in cheaper than assumed.</p></div>
<div class="note info"><span class="lbl">Context</span><p>Background the reader needs but did not ask for.</p></div>
<div class="note plain"><span class="lbl">Aside</span><p>Neutral, low-emphasis.</p></div>

15Waterfall chart

Why a number moved. Opening value, the movements that acted on it, closing value — the visual form of a “what changed the estimate” table.

Markup 
<figure>
  <div class="svgbox"><div id="wf-estimate"></div></div>
  <figcaption>The audit did not simply raise the estimate — it replaced a guess with six measured
  movements, three of which pushed down. Red adds hours, green removes them.</figcaption>
</figure>
<script>
document.addEventListener("DOMContentLoaded", function () {
  Report.waterfall("#wf-estimate", [
    { label: "Prior central estimate", total: true },
    { label: "Claim UX built from nothing", delta: 12 },
    { label: "No test harness exists",      delta: 9  },
    { label: "Plot derivation, five forms", delta: 8  },
    { label: "EF already in a DAL",         delta: -6 },
    { label: "Wire format preserved",       delta: -4 },
    { label: "Exports and clock rendering", delta: 11 },
    { label: "Post-audit central estimate", total: true }
  ], { start: 80, unit: " h", polarity: "cost" });
});
</script>
